# BC3.0 monitoring 구성

```
                      ┌─────────────────────────┐
                      │        Client           │
                      └────────────┬────────────┘
                                   │  port:443
                                   ▼
                      ┌─────────────────────────┐
                      │  MetalLB (L2/BGP mode)  │
                      │  LoadBalancer IP 할당   │
                      │  VIP: 172.27.213.110    │
                      └────────────┬────────────┘
                                   │
                                   ▼
                      ┌─────────────────────────┐
                      │  Gateway (Gateway API)  │
                      │  kind: Gateway          │
                      │  listener: 443/HTTPS    │
                      │  (실제로는 Service 타입  │
                      │   LoadBalancer로 노출됨) │
                      └────────────┬────────────┘
                                   │
                                   ▼
                      ┌─────────────────────────┐
                      │       HTTPRoute         │
                      │  path/host 기반 라우팅   │
                      │  parentRefs: Gateway    │
                      │  backendRefs: Service   │
                      └────────────┬────────────┘
                                   │
                                   ▼
                      ┌─────────────────────────┐
                      │    Service (ClusterIP)  │
                      │  selector: app=myapp    │
                      │  port: 443 → targetPort │
                      └────────────┬────────────┘
                                   │
                 ┌─────────────────┼─────────────────┐
                 ▼                 ▼                 ▼
          ┌────────────┐   ┌────────────┐    ┌────────────┐
          │  Node 1    │   │  Node 2    │    │  Node 3    │
          │            │   │            │    │            │
          │ ┌────────┐ │   │ ┌────────┐ │    │ ┌────────┐ │
          │ │ Pod    │ │   │ │ Pod    │ │    │ │ Pod    │ │
          │ │(Deploy)│ │   │ │(Deploy)│ │    │ │(Deploy)│ │
          │ └────────┘ │   │ └────────┘ │    │ └────────┘ │
          └────────────┘   └────────────┘    └────────────┘
```
