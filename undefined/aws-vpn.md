# AWS VPN 터널링

<pre><code>1. 고객 게이트웨이 생성
   VPC → 고객 게이트웨이 → 고객 게이트웨이 생성
   IP 주소 항목에 병원 공인IP 입력
2. VPN 연결 생성
   Site-to-Site VPN 연결 → VPN 연결 생성
   가상 프라이빗 게이트웨이 → AWS to HIS VPC 선택
   고객 게이트웨이는 생성한 고객 게이트웨이 설정
   라우팅 옵션 → 정적
   터널 옵션
      내부IPv4 CIDR, 사전 공유 키: 그대로
<strong>      1/2단계 암호화 알고리즘: AES256
</strong>      1단계 무결성 알고리즘: SHA2-384
      2단계 무결성 알고리즘: SHA2-256
      1/2단계 DH 그룹 번호: 20,21
      IKE 버전: ikev2
3. NAT 설정
   신규 생성한 VPN → 정적 경로 → 라우팅 편집
   병원 내 사설 IP 대역과 맞춰 정적 접두사 추가
4. 구성파일 다운로드하여 업체 전달 (NAT 1:1 설정 요청도 함께)

</code></pre>
